# DailyDex — Creator Cockpit

AI content strategist for creators: fetches developer signals (GitHub trending, HuggingFace, Hacker News, arXiv, YouTube), scores them, and generates video scripts, thumbnails, and multi-platform text assets via LLMs. Flask backend + React cockpit UI.

## Commands

```bash
# Tests (always use the venv — system python lacks deps)
.venv/bin/python -m pytest tests/ -q

# Single test file / test
.venv/bin/python -m pytest tests/test_routes.py -q
.venv/bin/python -m pytest tests/test_routes.py::test_refresh_endpoint_success_and_failure_preserves_data -q

# Run the app locally (serves on 127.0.0.1:8888)
.venv/bin/python src/dashboard_new.py

# Precompile cockpit JSX → JS (required after editing any .jsx in src/static/cockpit)
npm run build:cockpit

# Docker (production: gunicorn on :8888)
docker build -t dailydex . && docker run -p 8888:8888 dailydex
```

## Architecture

- **`src/dashboard_new.py`** — main Flask app (~3.6k lines, being split into blueprints). All routes live here except settings.
- **`src/routes/`** — extracted Flask blueprints (pattern: `api_settings.py`). New route groups go here.
- **`src/data_models.py`** — `IntelligenceDB` and persistence (SQLite by default, Postgres/Supabase when `DATABASE_URL` set, via `db_compat.py`).
- **`src/fetch_news.py`** — signal fetchers (GitHub/HF/HN/arXiv/YouTube). `src/scoring_engine.py` scores items into `data/data_scored.json`.
- **`src/llm_summary.py`** — `query_llm()` strategy-pattern dispatch across providers (CLI tools or direct REST: Anthropic, OpenAI, NVIDIA NIM, Gemini). BYOK keys via settings.
- **`src/creator_*.py`** — enrichment pipeline, intelligence deep-dives, creator lab (script/asset generation).
- **`src/static/cockpit/src/*.jsx`** — legacy React 18 cockpit views. Each `.jsx` has a precompiled `.js` sibling generated by `npm run build:cockpit` — **edit the `.jsx`, then rebuild; never hand-edit the `.js`**.
- **`frontend/`** — new Vite + React + TypeScript app (migration target for the legacy cockpit; in progress).
- **`api/index.py`** — Vercel serverless entrypoint; `vercel.json` config.
- **`video-engine/`** — Node-based video rendering.
- **`tests/conftest.py`** — `app_env` fixture builds a full temp app environment (data dirs, config, env vars) and re-imports `dashboard_new`. Also puts `src/` on `sys.path`.

## Conventions

- Refresh is async: `POST /api/refresh` returns `{"status": "running"}` immediately; poll `GET /api/refresh/status`.
- Config: root `config.json` (runtime, env-overridable via `CONFIG_FILE`), `config/topics.json`, `config/creator_profile.json`.
- Data files live under `data/` and are gitignored; tests use temp dirs, never real data.
- Scratch/experiments go in `scratch/` (gitignored), not the repo root.
- Workflow per git history: feature branches `fix/...` merged into `main`.
